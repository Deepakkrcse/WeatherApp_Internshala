# Weather App

## Description
A weather application that provides weather forecasts from openweathermap and current weather data of different locations.

## Features
- Search for weather by city.
- Display current weather conditions.
- Show a 5-day weather forecast.
- User location Feature(takes a couple of seconds to load)
- Recent searched cities

## Technologies Used
- HTML
- CSS (Tailwind CSS)
- JavaScript
- OpenWeatherMap API
